# Mac（Apple Silicon / Mシリーズ）

開くファイル：`KemoMichi-macOS-arm64.dmg`

1. DMGをダブルクリックします。
2. **KemoMichi** を **Applications（アプリケーション）** にドラッグします。
3. 「アプリケーション」から **KemoMichi** を開きます。

この開発用PCではmacOS 26で起動・画像表示・動画表示を確認済みです。
Developer ID署名・公証は未完了の試用版です。
DMGがない場合は、まだ配布ファイルを取得していません。[入手方法](../../README.md#入手方法) を確認してください。
