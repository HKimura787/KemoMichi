# Windows（x64）

現在はビルド・動作確認待ちです。配布ファイルを入手後、次の手順で起動します。

## インストーラー版

1. `KemoMichi-Windows-x86_64-setup.exe` を開きます。
2. 画面の案内に沿ってインストールします。
3. スタートメニューから **KemoMichi** を開きます。

## ポータブル版

1. `KemoMichi-Windows-x86_64-portable.zip` を右クリックし、「すべて展開」を選びます。
2. 展開した `KemoMichi` フォルダの中の `KemoMichi.exe` を開きます。

同梱のフォルダ・ファイルはまとめて保持してください。EXEだけを移動すると動作しません。
コード署名は未完了です。起動を拒否された場合は、表示されたメッセージを開発者へ知らせてください。
