# PR用の説明

## 変更内容

tdbを選んで直ちにddbを作る操作に、入力項目の編集と確認を追加します。
元のtdbを変更せず、確定版tdbとddbを同名で作成します。
列の追加・削除・並べ替え、表示名・CSV列名・型・選択肢・初期値の編集に対応し、必須項目と既存ファイルを保護します。

画像・動画の一覧に加え、全レコードを直接編集できる「入力データ」ビューを追加します。
複製したデータやRESTイベントのレコードも確認でき、複数選択・入力エラー・読み取り専用・自動記録列の保護に対応します。
閲覧用の一覧では、mainと同じくイベントの複製行をまとめて表示します。

プロジェクト選択画面から戻る操作、パス指定、判読位置・動画フレームの再開、ddbと同名のCSV、
動画操作・画像保存、メディアキャッシュの容量制限も含みます。
キャッシュは既定2 GiBで、生成・配信中のファイルを保護しながら古いものから整理します。

mainのRESTイベント、動画をまたぐ滞在時間の計算、個体番号の自動採番と種名記録を保持します。
補助アプリのビルドは、作業用フォルダに定義を生成する形にし、削除済みの配布用フォルダへの参照を解消します。
README.mdはmainの内容を維持します。

## レビューの順序

1. tdbの編集・検証・保存：`template_edit.py`、`template_models.py`、APIの `/api/template` と新規作成処理、`TemplateWizard.tsx`。
2. 入力データとmain機能の共存：`Spreadsheet.tsx`、`Workspace.tsx`、一覧APIの `records` オプション、同名tdbの優先選択。
3. キャッシュと補助アプリ：`media.py`、`media_response.py`、`desktop.py`、`tools/package_desktop.py`。
4. 回帰テストと文書。`src/kemoserver/static/` は `npm run build` の生成物です。

mainの取り込みは独立したマージコミットにしています。入力形式・元tdbの保持・上書き拒否・WAL内の変更検出と、
確定したテンプレートからの個体別イベント作成・全レコードの一覧表示を回帰テストで確認します。

