# tdbの入力項目を確認・編集して新しいddbを作る

1. 「プロジェクトを開く」で **tdbから新規作成** を選びます。
2. 画像・動画があるフォルダを選び、**tdbを選んで項目を設定…** を押します。
3. 元になるtdbを選び、**内容を読み込んで編集** を押します。
   tdbが別の場所にある場合も、ファイル・フォルダのパスで移動できます。
4. プロジェクト名と入力項目を設定します。
5. **作成内容を確認** で、項目一覧と作成するtdb・ddbのパスを確認します。
   修正するときは **編集に戻る** を押します。
6. **確定してddbを作成** を押すと、画像・動画を取り込み、新しいプロジェクトが開きます。

## 編集できる内容

- 項目の追加・削除・並べ替え
- 画面に出す表示名と、CSVに出す列名
- 入力形式：テキスト、複数行、単一・複数選択、チェック、個数、整数、小数、英数字、日時、日付、時刻
- 選択肢と初期値（新しく取り込む画像・動画の各行に設定されます）
- 入力時の説明、入力欄の幅、画面への表示、CSV出力、前のファイルからのコピー可否

CSV列名は、英字で始まる半角英数字・`_` とし、他の列名やSQL予約語と重ならない名前にします。
表示名は日本語を使用できます。選択肢は1行に1つ入力します。
複数選択の初期値は `歩行,採食` のようにカンマで区切ります。

ファイル名・相対パス・撮影日時・削除フラグは必須項目です。
表示名や表示・出力設定は編集できますが、削除や型・列名・初期値の変更はできません。

## 保存するファイル

元のtdbは変更せず、確定版のtdbとddbを画像・動画フォルダへ同じ基本名で新規作成します。
例：プロジェクト名が `調査2026` なら `調査2026.tdb` と `調査2026.ddb` です。
CSVの既定名は `調査2026.csv` です。

通常は元のtdbの基本名を提案します。作成先に同名のtdbまたはddbがある場合は、
`調査_project` などの別名を提案します。既存ファイルは上書きしません。
確定版tdbにはフォルダ項目やテンプレートのメタデータも引き継ぎます。

「作成内容を確認」まではファイルを書き込みません。「やめる」で終了しても元のtdbと既存ddbは変更しません。
読み込み後に別のアプリが元のtdbを変更した場合は、古い内容で作成せず、読み込み直しを求めます。
